# CLASO

Pakistan's beauty & makeup storefront, built with React (Create React App) and Firebase.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page reloads automatically as you edit files.

### `npm run build`

Builds the app for production into the `build` folder, minified and ready to deploy.

### `npm test`

Launches the test runner in interactive watch mode.
